## 本轮新增覆盖

- 八个并发重复提交只创建一个任务、一条工具作业。
- 同一请求 ID 对应不同文本或不同模式时返回 409；模型暂不可用时，已完成请求仍能去重读取。
- 过期 interrupt 被拒绝；确认节点不接受普通补充事件；拒绝操作不写入。
- 候选序号越界后继续等待，重新选择可恢复，不重复检索。
- 等待旧任务时创建新任务；一句显式复合回复同时恢复选择并创建独立任务。
- 独立领域工具同时在途；依赖任务在前置成功后才启动并绑定真实状态结果。
- 前置失败时下游写任务不启动；取消父任务后拒绝迟到恢复，保留已完成兄弟结果。
- 无效依赖、环、重复任务 ID、非依赖结果绑定及超过六项的计划被拒绝。
- 工具超时进入 Dead Letter，其他分支继续执行；依赖失败不调度下游工具。
- 工具取消后收到迟到成功回执，保持取消状态，同时保留回执证据。
- SSE 超过 200 条时跨页回放完整，游标使用查询参数与 Last-Event-ID 的较大值。
- 模型流式生成中途失败，以已取得的工具事实替换残缺回复，不直接拼接错误文本。
- 未配置真实模型时返回 503，不静默切换 demo。
- Trace、依赖图、恢复和取消接口的用户命名空间隔离。
- 健康知识检索、风险信号和交接事件；事件不代表外部人工系统已经接单。
- 前端并行层级、依赖边、汇合、分支当前阶段，以及取消/恢复后的状态优先级。

## 发现并修复的问题

### 请求去重未校验内容

此前只按 request_id 返回旧任务，不比较请求文本与模式。现在同时校验用户、会话、文本和模式；内容冲突返回 409，不把另一条指令吞掉。去重先于模型可用性检查，不要求重新调用模型才能读到旧请求结果。

### 中断事件类型未校验

此前 approval 收到 answer 也会进入恢复节点，可能被当成拒绝。现在 approval 只接受 approve/reject，selection 和 clarification 只接受 answer；类型不匹配返回 422，原中断保持有效。

### 迟到工具结果覆盖取消

通过一个收到取消后仍返回结果的受控适配器复现：作业先被取消，再被迟到回执改成 completed。现在完成、重试和 Dead Letter 都要求原状态仍为 running；取消状态不会复活。迟到回执保存到 result_json，并发布 tool.late_result。

这保证的是本地状态一致性，不代表远端副作用回滚或远端恰好执行一次；结果未知时仍须对账。

### 执行图使用旧事件覆盖最新状态

父图优先采用子任务终态快照，不再因旧的 started/interrupt 事件把取消分支显示为运行或等待。领域内部图按事件序号比较最近开始、完成和等待，已经完成的前置节点不会随任务失败一起变红，恢复后的节点也不会一直保留旧等待状态。

## 真实服务验证

MCP 直接工具验收使用临时 SQLite 库，确实完成写入、幂等复用、冲突拒绝、提醒到期与只投递一次。测试结束清理临时库。天气、地点、音乐向实际服务发出请求，不使用模拟兜底。

HTTP 验收在 `http://127.0.0.1:8001` 的新版本上进行，使用独立的 `data/regression-runtime.sqlite3`。每次脚本生成新的验收用户；本轮保留一条标题含“验收测试”的行程作为证据，不修改已有用户会话。

- “请查询天气”先询问城市，回答“无锡”后取得高德天气回执并完成回复。
- 拒绝保存行程后，行程条数为 0。
- 确认保存后，真实行程条数为 1；重复确认返回 409，写工具完成事件只有一次。
- 跨会话偏好读取成功；其他用户读取原会话返回 404。
- Trace 包含有序事件，持久化检查点可读，人工审核内容可保存并按审核状态筛选。
- “查询无锡今天的天气，同时搜索陶喆的歌曲”：音乐保持待选择时天气独立完成；随后选择歌曲，父任务汇总成功。

## 未验证与边界

- 高德 30001 处理未改，驾车、步行、骑行三个真实路线场景本轮跳过，不声明导航问题已解决。
- 浏览器授权被拒绝，未验证按钮点击、滚动、刷新后的实际渲染、移动布局和截图。前端构建通过不等于 UI 验收通过。
- 当前验收实际使用 SQLite、本地记忆和 local-vector 知识检索，未实测 Redis、MySQL、PostgreSQL、Chroma 生产后端。
- auth_mode 为 local；X-Demo-User 测试证明命名空间隔离，不等于生产登录鉴权或安全渗透测试。
- 旧 8000 进程无法由本轮执行环境停止，未替换；8001 是修复后的独立验收实例。
- 没有开展并发压测、长期稳定性测试或生产流量验证；也没有重新测量简历中的准确率。
