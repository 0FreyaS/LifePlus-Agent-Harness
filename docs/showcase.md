## 四任务案例

在真实模型模式输入 README 的四任务请求：地点检索、无锡天气、周杰伦歌曲并行，路线依赖地点所选坐标。不要为截图向数据库插入一份预制成功计划，也不要用规则返回冒充真实模型。

```bash
uv run --frozen --extra dev --extra music python -m evaluations.showcase_smoke \
  --base-url http://127.0.0.1:8000 --output data/showcase/new-run
```

该脚本会创建一个新的测试会话并消耗真实服务额度，候选只从工具实际提供的列表选择第一项，不确认写操作。密码保护服务使用进程环境中的 `SHOWCASE_USERNAME` 和 `SHOWCASE_PASSWORD`；不能把密码放到 URL 或报告。原始任务与事件仅写本地忽略目录，公开摘要剔除会话标识和完整 Trace。

判断标准不是“图看起来有四个框”，而是：恰好四个子任务、三个独立入口、路线有地点依赖；独立分支至少一对执行区间重叠；依赖完成先于路线启动；路线 origin 与真实选中地点一致；四项目标都有成功回执。失败运行应保留，不通过改图或删报告改成成功。
