v1至v3为迭代中间版本，实际被测输入随各轮结果独立归档。最终版本不是每条都已有真实执行证据；不得把100/370/290写成通过数。复现命令及边界见[修复说明](../../../docs/evaluation-calibration-20261106.md)。
