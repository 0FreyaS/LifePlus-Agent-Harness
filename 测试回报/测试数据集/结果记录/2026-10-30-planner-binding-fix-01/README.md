# 全局规划绑定修复实测

两组均DeepSeek Flash、关闭思考、2048有效输出上限、单次25秒/累计45秒、一次结构修复。同一进程复用同一客户端；对照加载与前次实测hash一致的Git修复前两文件快照，候选为当前仓库两文件。不切Git分支或工作区，不修改.env，不执行业务工具。37场景随机、逐场景AB/BA轮换。

- cases.jsonl：原7失败＋新增30长尾；输入、期望及scope。
- results.jsonl：74条观察的最终JSON、评分、异常、修复次数与全部用量；不保存隐藏推理文本。
- manifest.json：模型、预算、数据hash、修复前commit和两组源代码hash。
- baseline_source/：受测原始两文件，便于复算错误，不是当前生产实现。
- summary.json：7和30两个分母分开；该集定向富集绑定失败，不代表一般规划总体准确率。
- original30/（若存在）：修复后另测完整D04，检查原有非绑定场景回归；单臂，不与旧观察拼成新A/B。

- 工程回归摘要.json（若存在）：不含私有.env的隔离源码副本受控测试；不计入模型准确率。

数据为人工合成，标签及评分覆盖数量/领域/关键词/依赖/绑定，不是完整自然语言质量、实际写入或端到端完成率。部分原7与D04重叠，不能把数量相加当独立样本；正常服务没有在此实验中部署或重启。
